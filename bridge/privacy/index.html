Prize Bridge Privacy Notice

How the private Bridge utility is designed to use Google Apps Script project data.

17 November 2026 · Technical notice Bridge overview Prize Privacy Notice Contact

1. Scope and operator

This notice applies to MIELOGOS Prize Bridge, a private technical tool used by the MIELOGOS Literary Prize operator to check the integrity of Google Apps Script source files. It does not govern applications for the literary prize; those are covered by the separate Prize Privacy Notice.

Responsible operator and privacy contact: MIELOGOS Literary Prize, prize@mielogos.com.

2. Google data requested

The Bridge is configured to request the sole OAuth scope https://www.googleapis.com/auth/script.projects.readonly. This read-only scope can expose the source files and project metadata of Google Apps Script projects the authorizing Google account is permitted to access. It does not authorize changing, publishing or deleting Apps Script source.

The intended automated operation uses only one specified non-production test project. This limitation is imposed by the Bridge workflow, not by the Google OAuth scope itself. Source files may contain configuration details or embedded data; they must therefore be treated as potentially confidential.

3. Purpose and processing

When separately authorized and activated, the proposed workflow will temporarily retrieve the designated test project's source, compare it with the operator's private version-control source and identify source drift. The comparison can process file contents, filenames and cryptographic hashes; a retained evidence report is designed to contain filenames, counts and SHA-256 hashes, not the raw source or OAuth credentials.

The project is in technical testing. As of the date of this notice, the Bridge has not yet been connected to live Google OAuth access. This notice describes the intended processing if it is activated.

4. Storage, providers and retention

The planned check executes on short-lived private GitHub Actions runner infrastructure. Project source is used transiently for comparison and is not intended to be included in the retained report. The proposed private report is retained for seven days; GitHub and Google may retain operational logs or account metadata according to their own service policies and settings.

OAuth credentials, if provisioned, will be held in private GitHub Actions secrets and used to obtain access tokens for the defined read-only request. Such credentials are not intended for publication or inclusion in the repository, report or application web pages.

5. Sharing and prohibited uses

Authorized Prize operators and the cloud service providers needed to carry out the check (Google and GitHub) may process the data for the stated technical purpose. The Bridge is not designed to sell Google user data, use it for advertising, or use Google user data to train AI models. It does not offer a public interface for third parties to access Google user data.

The Bridge's handling of Google user data is intended to comply with the Google API Services User Data Policy, including its applicable Limited Use requirements.

6. Access control, revocation and questions

The Google account owner chooses whether to grant the requested scope. Authorization may be withdrawn through the Google Account third-party connections settings. The operator may also disable the relevant GitHub workflow and remove its stored credentials. Revocation does not necessarily erase previously generated limited evidence reports; those follow the retention period stated above.

For access, retention, correction or privacy questions, contact prize@mielogos.com.
