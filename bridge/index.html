MIELOGOS Prize Bridge

A private, read-only source-verification utility for the Prize's Google Apps Script infrastructure.

Technical testing Bridge Privacy Notice Prize Privacy Notice Prize contact

What the Bridge does

MIELOGOS Prize Bridge is an operator-only technical utility for the MIELOGOS Literary Prize. Its planned purpose is to read and compare authorized Google Apps Script source files against private version-control records, so that unintended source differences can be detected before any separate deployment decision.

It is not a public submission form, judging application or service for entrants. It does not invite outside users to sign in.

Google access requested

During the current test phase, the application is configured to request only the Google Apps Script permission https://www.googleapis.com/auth/script.projects.readonly. This permission can allow reading source files of Google Apps Script projects accessible to the Google account that authorizes it. It does not allow the Bridge to change, delete or deploy Apps Script projects through that permission.

The planned automated check is restricted in its code to one designated test project. The OAuth permission itself is account-wide for accessible Apps Script projects, rather than restricted by Google to that test project. The Bridge has not yet been connected to live Google OAuth access.

How the verification works

The proposed workflow temporarily reads test-project source into a private GitHub Actions runner, compares it against the private source repository and generates a limited report of filenames, file counts and cryptographic hashes. It is designed to avoid including raw source code or OAuth credentials in saved reports and workflow logs. Any mismatch blocks the check; it is not automatically repaired.

No production source update or deployment is authorized by this read-only check. Any future write-capable workflow would require separate permissions and explicit safeguards.

Privacy and contact

For information about Google data access, processing, retention and revocation, read the MIELOGOS Prize Bridge Privacy Notice. The Prize Privacy Notice applies separately to literary submissions and Prize administration.

Operator contact: prize@mielogos.com.
