# MIELOGOS v0.9 deployment notes

Upload `MIELOGOS_Prize_GitHub_Staging_v0.9.zip` to the repository root and run the existing Bootstrap workflow.

After deployment, open `/research/prior-art/` on mobile:
- the header and article should render at the same normal scale as the rest of the site;
- there should be no page-level horizontal overflow;
- only the comparative evidence matrix should scroll horizontally inside its own frame.
